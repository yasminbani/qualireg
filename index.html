Qualitative regression models

Self-Instructional Material · 3 hours

    Formula sheet

    Binary Y

    E(Y | X) = 1·Pr(Y=1|X) + 0·Pr(Y=0|X) = Pr(Y=1|X)

    Linear probability model

    Pr(Y=1|X) = β0 + β1X

    β1 = change in probability for a unit change in X. Use heteroskedasticity-robust SEs.

    Probit

    Pr(Y=1|X) = Φ(β0 + β1X),   Φ = standard normal CDF

    β1 = change in the z-index for a unit change in X.

    Logit

    Pr(Y=1|X) = F(β0 + β1X) = 1 / (1 + e−(β0+β1X))

    Effect of a change in X (probit/logit)

    ΔP = G(β0+β1(X+ΔX)) − G(β0+β1X),   G = Φ or F

    Measures of fit

    Fraction correctly predicted: share of observations with p̂ > 0.5 when Y=1, or p̂ < 0.5 when Y=0.

    pseudo-R² = 1 − ln(fmax) / ln(f0)

    fmax = maximised likelihood with the X's; f0 = likelihood with only an intercept.
